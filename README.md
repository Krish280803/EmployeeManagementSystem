# Employee Management System

 Overview

This project is a simple Employee Management System developed using Java.

The application allows users to:

* Add Employee Details
* View Employee Records
* Search Employee by ID
* Handle Employee Not Found Exceptions

 Concepts Used

* Object Oriented Programming (OOP)
* ArrayList Collection
* Custom Exception Handling
* Java 8 Stream API
* Optional Class
* Console-based Application

 Files Included

* Employee.java
* EmployeeService.java
* EmployeeNotFoundException.java
* Main.java

 Features

* Add Employee
* View Employees
* Search Employee
* Exception Handling

 Technologies Used

* Java
* Eclipse IDE

 Output

The application runs in console mode and provides a menu-driven Employee Management System.
